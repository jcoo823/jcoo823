# Calculator App

A simple GUI calculator application built with Python and Tkinter.

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Decimal number support
- Clear function
- Plus/minus toggle
- Percentage calculation
- Error handling for invalid operations
- Clean, intuitive user interface

## Requirements

- Python 3.x
- Tkinter (usually included with Python)

On Ubuntu/Debian systems, if Tkinter is not available:
```bash
sudo apt-get install python3-tk
```

## Usage

Run the calculator:
```bash
python3 calculator.py
```

## Controls

- **Number buttons (0-9)**: Input numbers
- **Operation buttons (+, -, ×, ÷)**: Perform arithmetic operations
- **= button**: Calculate result
- **C button**: Clear calculator
- **± button**: Toggle positive/negative
- **% button**: Convert to percentage
- **. button**: Add decimal point
